## 销售模式，并非实际月付价

低价 VPS 圈子里最常见的口径是“年付摊月”，把一年总价除以 12 得到的数字，用来和月付套餐放在一张表里比较。RackNerd 自己就把 1 核 1G / 20G 的套餐写成“21.99 USD 年付、12.20 元/月”，而同一家同规格的 KVM-1GB 月付是 17.99 USD/月，折合约 120 元/月。同一台机器，月付一年要付 $215.88，年付只要 $21.99。

这个差额说明两件事。第一，判断性价比要看一次性支出，而不是只有“每月多少钱”这一个数：SixtyNet 全系都是年付价，最低一档也要一次付 $50，最高一档 $1600。第二，要问清楚第二年续费是否还按这个价，以及用不满能不能退。

SixtyNet 的年付折扣写得很明确：LAX 系列年付比月付省 17%，Residential-STARTER 从 $300 降到 $260，省 13%；季付省 10%，半年付省 7%。如果只是短期项目，季付的折扣少 7 个百分点，但能少压 9 个月的钱在里头。

## 两条会直接决定能不能用的限制

住宅 IP 的卖点是“看起来像真人家庭宽带”，代价是这批 IP 被风控系统盯得紧，商家不敢让它们跑公开网站。SixtyNet 在 Residential 系列的产品页上明确写了：出于 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。也就是说，你不能在这台机器上直接挂网站、跑 HTTPS 服务。要建站，选 LAX 系列，它带 DDoS 防护，端口是正常开放的。

带 AS9929 优化的住宅 IP 版本还多一层限制：产品页写明这套方案会拒绝所有外部探测和扫描，访问默认关闭，只有自己配了白名单或端口转发的设备能连进去。稳定性是上去了，但上手成本也跟着上去，得先会配防火墙规则。同一段文字里还有一句容易被略过的话：这款产品的退款只退到网站余额，不退回原支付渠道。

退款窗口也短。第三方测评提到 SixtyNet 的退款期是 3 天，不是行业里常见的 30 天。3 天够你开机、测延迟、验证 IP 属性，但不够你把一个项目跑起来再说“不合适”。下单后第一件事应该是测全国丢包率和 IP 归属，别拖到第五天才想起来。

## AS9929、CN2 GIA、163 骨干网到底差在哪

这三条线路的差别体现在晚高峰时段。163 骨干网是电信最基础的出口，节点以 202.97 开头，用的人最多，优化最少，出国方向晚高峰拥堵和丢包都比较明显。CN2 GT 是中端产品，去程和回程都可能混入 202.97 节点，晚高峰仍会堵。CN2 GIA 是电信最高一档，路径基本全程走 59.43 节点，最稳，价格也最高。AS9929 是原网通骨干、现在的联通第二大网，CMI 则是移动自己的国际出口。

第三方测评汇总的的美国线路延迟区间大致是：CN2 GIA 150–180ms、AS9929 120–150ms、AS4837 150–200ms（非官方数据，只作量级参考）。SixtyNet 官网给 AS9929 方案标的是 100M 基础网络、3 倍突发速率、95 计费，这种配置适合流量有波峰但不需要长时间跑满的业务。

反过来看，RackNerd 这类年付十几元每月的机器明确说明“没有 CN2，走普通国际线路”。白天用没感觉，晚高峰跑实时业务就会掉速。如果你的用途是个人博客、定时任务、备份节点，普通线路完全够；如果是跨境直播、稳定访问 AI 服务、社媒账号运营，线路和 IP 属性的钱省不掉。
